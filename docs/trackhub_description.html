hotspot3 peak calls for chromatin accessibility data

Description

hotspot3 is a peak caller for chromatin accessibility data. It is tailored to work on datasets without a control experiment (ATAC-seq and DNase-seq) using adaptive estimation of the background (nonspecific cleavages) with a negative binomial distribution. hotspot3 accounts for variation in both total signal level and signal-to-background ratio along the genome.

Data included in this trackhub

  • Density and background (overlaid):
    • Normalized density (black): per-base cut count density, in cuts per million.
    • Background (orange): estimated background level at each position, from the local negative binomial model (corresponds raw p-value cutoff 0.005). Signal above the orange track exceeds the modeled background and can potentially be significant (after FDR correction).
  • Hotspots at each FDR threshold: contiguous regions of signal enrichment. Thick blocks mark stretches of significant bases; the score reflects the maximum -log10 FDR in the hotspot. Darker purple marks more stringent FDR thresholds.
  • Peaks at each FDR threshold: peaks detected from the smoothed signal that overlap significant bases. The tick marks the peak summit; the score reflects the maximum density in the peak. Darker green marks more stringent FDR thresholds.

Methods

The main algorithm steps are:

  1. Adaptive background modeling using a negative binomial distribution, fitted within locally uniform genomic segments.
  2. Bayesian segmentation (via BABACHI) to partition the genome into regions with a homogeneous background (i.e., similar signal-to-noise ratio, modeled using a common overdispersion parameter in the background model).
  3. Per-base statistical testing to assign p-values and estimate FDR for enrichment at each position.
  4. Signal smoothing using the Maximal Overlap Discrete Wavelet Transform (MODWT) to suppress local noise and normalize fine-scale variability (e.g., transcription factor footprints).
  5. Hotspot calling, which identifies contiguous regions of signal enrichment at a specified FDR threshold.
  6. Peak calling, which detects peaks from the smoothed signal and reports those that overlap with significant bases.

Background model

The background is fitted separately in each segment. Only the lower part of the signal distribution is modeled as background (by default the lowest 99.5% of positions), which excludes extreme outliers such as regions with unusually high coverage. Segments whose fit assigns too much signal (a signal-to-noise ratio above 5x the global weighted median) are re-fit with a minimum background proportion, which prevents overcalling peaks, e.g. near telomeres and centromeres. In segments where a negative binomial distribution cannot be fitted (typically very low signal), no peaks are called.

Quality control

For each segment, hotspot3 reports the background fit ({sample_id}.fit_stats.bed.gz) and the SPOT score (Signal Proportion Of Tags): the proportion of tags not used to fit the background, i.e. signal tags. The overall SPOT score, the weighted median of segment SPOT scores, is a dataset-level quality metric. See Flagging problematic segments for how to interpret the segment flags.
